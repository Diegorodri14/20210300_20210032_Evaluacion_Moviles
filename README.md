****Descripcion****

Nuestro proyecto se basa en un sistema de control y registro de estudiantes, en el cual contiene toda la informacion de estuadiante con su carnet y fecha de nacimiento

Teniendo nuestra pagina un diseño llamativo visualmente con colores turquesa con sus diferentes tonalidades haciendo que le de un color pastel a nuestro sistema
